Добавить видео

В Instagram: «Поделиться» или ⋯ → «Копировать ссылку». Добавленное сразу видно на этом устройстве. Чтобы видео увидела дочка — сохраните список на GitHub (ниже).

Видео

    Пока вы вошли, в ленте справа сверху видна кнопка ✕ — ею убирают неработающее видео, не заходя сюда. Через 15 минут она спрячется сама, и дочка её не увидит.

    Сохранить для дочки

    Открыть videos.json ↗
    1. «Скопировать список».
    2. «Открыть videos.json ↗» → карандаш (Edit).
    3. Выделить всё в файле и вставить скопированное.
    4. Зелёная кнопка Commit changes.
    Через минуту нажмите «Обновить с GitHub» — видео станут общими, и телефон дочки их подхватит.

    Вид

    Instagram не говорит, какой высоты у него плеер, поэтому кадр подгоняется вручную — один раз. Двигайте ползунки, пока в окошке не останется одно видео: без имени канала сверху и без лайков снизу.
