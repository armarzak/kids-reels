# Видео для дочки

Лента Instagram Reels, которую листаешь как в TikTok, но показывает она **только те видео, которые добавил родитель**. Ни поиска, ни рекомендаций, ни перехода в само приложение Instagram.

**Открыть:** https://armarzak.github.io/kids-reels/

## Как смотреть

Открыть ссылку в Safari/Chrome на телефоне → «Поделиться» → **«На экран Домой»**. Появится иконка, приложение откроется на весь экран.

Листать вверх-вниз. Звук пролистанного видео выключается сам.

## Как добавить видео

### Коротко

1. В Instagram у нужного Reels: «Поделиться» → **«Копировать ссылку»**.
2. Открыть [videos.json](../../edit/main/videos.json) → карандаш (Edit).
3. Добавить ссылку новой строкой в кавычках, через запятую.
4. **Commit changes**.
5. На телефоне дочки открыть приложение — сверху появится плашка «Новые видео — обновить».

Файл выглядит так:

```json
[
  "https://www.instagram.com/reel/C8xYz1AbCdE/",
  "https://www.instagram.com/p/DA2bQ9kLmNo/"
]
```

Порядок строк = порядок в ленте. Удалить видео = удалить строку. Последняя ссылка — **без** запятой на конце.

### Через само приложение

Удобнее, если ссылок много:

1. Открыть приложение, **удерживать шестерёнку** в правом верхнем углу 1,5 секунды.
2. Ввести PIN (в первый раз — придумать, минимум 4 цифры; он хранится только на этом устройстве).
3. Вставить ссылки в поле → **«Добавить»**. Можно сразу несколько, лишний текст не мешает.
4. Кнопкой ▶ проверить, что видео открывается.
5. **«Скопировать список»** → **«Открыть videos.json ↗»** → карандаш → выделить всё в файле и вставить → **Commit changes**.
6. Через минуту — **«Обновить с GitHub»**. Метка видео сменится с «новое» на «общее»: значит оно теперь у всех.

Пока ссылка не сохранена в `videos.json`, она помечена «новое» и видна только на том устройстве, где её добавили.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение: лента, режим родителя, PIN |
| `videos.json` | общий список видео — единственный файл, который нужно править |
| `manifest.webmanifest`, `icon*` | иконка и запуск с экрана «Домой» |

Видео играются во встроенном плеере Instagram (`/embed/`) внутри `iframe` с ограничениями: без `allow-popups` и `allow-top-navigation`, поэтому из плеера нельзя уйти в Instagram и попасть в общую ленту.

## Ограничения, о которых стоит знать

- Работают только **публичные** посты и Reels. Закрытый аккаунт во встроенном плеере не покажется.
- PIN и локально добавленные ссылки лежат в `localStorage` браузера. Это защита от ребёнка, а не от взрослого: очистка данных сайта сбрасывает PIN.
- Репозиторий публичный (иначе GitHub Pages требует платный тариф), так что список ссылок технически доступен по адресу репозитория. Сами посты и так публичные.
