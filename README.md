# Видео для дочки

Лента Instagram Reels, которую листаешь как в TikTok, но показывает она **только те видео, которые добавил родитель**. Ни поиска, ни рекомендаций, ни перехода в само приложение Instagram.

**Открыть:** https://armarzak.github.io/kids-reels/

## Как смотреть

Открыть ссылку в Safari/Chrome на телефоне → «Поделиться» → **«На экран Домой»**. Появится иконка, приложение откроется на весь экран.

Листать вверх-вниз. Звук пролистанного видео выключается сам.

## Как добавить видео

### Коротко

1. В Instagram у нужного Reels: «Поделиться» → **«Копировать ссылку»**.
2. Открыть [videos.json](../../edit/main/videos.json) → карандаш (Edit).
3. Добавить ссылку новой строкой в кавычках, через запятую.
4. **Commit changes**.
5. На телефоне дочки открыть приложение — сверху появится плашка «Новые видео — обновить».

Файл выглядит так:

```json
[
  "https://www.instagram.com/reel/C8xYz1AbCdE/",
  "https://www.instagram.com/p/DA2bQ9kLmNo/"
]
```

Порядок строк = порядок в ленте. Удалить видео = удалить строку. Последняя ссылка — **без** запятой на конце.

### Через само приложение

Удобнее, если ссылок много:

1. Открыть приложение, **удерживать шестерёнку** в правом верхнем углу 1,5 секунды.
2. Ввести PIN (в первый раз — придумать, минимум 4 цифры; он хранится только на этом устройстве).
3. Вставить ссылки в поле → **«Добавить»**. Можно сразу несколько, лишний текст не мешает.
4. Кнопкой ▶ проверить, что видео открывается.
5. **«Скопировать список»** → **«Открыть videos.json ↗»** → карандаш → выделить всё в файле и вставить → **Commit changes**.
6. Через минуту — **«Обновить с GitHub»**. Метка видео сменится с «новое» на «общее»: значит оно теперь у всех.

Пока ссылка не сохранена в `videos.json`, она помечена «новое» и видна только на том устройстве, где её добавили.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение: лента, режим родителя, PIN |
| `videos.json` | общий список видео — единственный файл, который нужно править |
| `scripts/telegram-bot.mjs` | бот: читает сообщения, дописывает ссылки |
| `.github/workflows/telegram.yml` | расписание опроса Telegram |
| `manifest.webmanifest`, `icon*` | иконка и запуск с экрана «Домой» |

Видео играются во встроенном плеере Instagram (`/embed/`) внутри `iframe` с ограничениями: без `allow-popups` и `allow-top-navigation`, поэтому из плеера нельзя уйти в Instagram и попасть в общую ленту.

## Бот в Telegram

Самый быстрый способ добавить видео: кинуть ссылку боту. Он сам допишет её в `videos.json`, и через пару минут видео появится у дочки.

Бот умеет:

| Сообщение | Что делает |
|---|---|
| ссылка (можно несколько сразу) | добавляет в начало ленты |
| `/list` | показывает, что сейчас в ленте |
| `/del <код>` | убирает видео |
| `/start`, `/help` | подсказка |

### Как подключить

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → имя и адрес бота. В ответ придёт токен.
2. Положите токен в секреты репозитория — **токен нигде не публикуется и в репозиторий не попадает**:
   ```
   gh secret set TELEGRAM_BOT_TOKEN --repo armarzak/kids-reels
   ```
   Команда спросит токен и примет его скрытым вводом. То же можно сделать мышкой: Settings → Secrets and variables → Actions → New repository secret.
3. Напишите боту любое сообщение. В ближайшие минуты он ответит вашим ID.
4. Разрешите этот ID — иначе бот никого не слушает:
   ```
   gh variable set TELEGRAM_ALLOWED_IDS --repo armarzak/kids-reels --body "ВАШ_ID"
   ```
   Несколько человек — через запятую.
5. Кидайте ссылки.

Сообщения от всех, кого нет в `TELEGRAM_ALLOWED_IDS`, бот молча игнорирует.

### Почему не мгновенно

Боту нужен сервер, который держит вебхук; отдельного сервера тут нет, поэтому GitHub Actions раз в пять минут сам спрашивает Telegram, нет ли новых сообщений (`.github/workflows/telegram.yml`). Отсюда задержка: обычно пара минут, иногда до десяти — GitHub не гарантирует точность расписания. Нужно быстрее — нажмите Run workflow на вкладке Actions, проверка пойдёт сразу.

Ещё одно: если в репозитории два месяца не будет коммитов, GitHub отключает расписание и присылает письмо — включается одной кнопкой.

## Вид без лишнего

В режиме родителя есть галочка **«Прятать имя канала и лайки»** (включена). Окно подгоняется ровно под видео: шапка с именем канала уезжает вверх за край, строка лайков и комментариев — вниз. Останется только картинка.

Расчёт опирается на пропорции: Reels — вертикальные 9:16, обычный пост плеер показывает квадратом. Если какое-то видео обрежется или снизу покажется полоска — снимите галочку, вернётся обычный плеер Instagram.

## Ограничения, о которых стоит знать

- Работают только **публичные** посты и Reels. Закрытый аккаунт во встроенном плеере не покажется.
- **Карусель** (пост из нескольких слайдов, ссылка с `img_index=`) встроенный плеер показывает только первым слайдом — пролистать к нужному нельзя. Если видео лежит девятым слайдом, добраться до него не получится; нужна отдельная ссылка на Reels. При добавлении такой ссылки приложение предупредит.
- PIN и локально добавленные ссылки лежат в `localStorage` браузера. Это защита от ребёнка, а не от взрослого: очистка данных сайта сбрасывает PIN.
- Репозиторий публичный (иначе GitHub Pages требует платный тариф), так что список ссылок технически доступен по адресу репозитория. Сами посты и так публичные.
